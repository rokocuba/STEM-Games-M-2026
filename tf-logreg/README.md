# TF-IDF + Logistic Regression Detector

This folder contains a text-only baseline model for detecting whether a Reddit comment was written by a human or generated by AI.

The model uses TF-IDF features and logistic regression. It does not use metadata such as username, karma, timestamps, account age, or subreddit history.

## Files

### `train.py`

Trains the classifier from a labeled CSV file.

Expected input columns:

```csv
comment,label
"example comment",AI
"another comment",HUMAN
```

What it does:

- Loads a CSV file with `comment` and `label` columns.
- Removes rows where either field is missing.
- Splits the dataset into train and test parts with stratification.
- Builds a `sklearn` pipeline with two TF-IDF vectorizers:
- Word TF-IDF with unigrams and bigrams.
- Character TF-IDF with character n-grams of length 3 to 5.
- Combines those feature sets using `FeatureUnion`.
- Trains a `LogisticRegression` classifier with balanced class weights.
- Prints accuracy, classification report, and confusion matrix.
- Saves the trained model as a `.joblib` file.

Example:

```bash
uv run python tf-logreg/train.py --data data/train.csv
```

Custom output path:

```bash
uv run python tf-logreg/train.py --data data/train.csv --model-out tf-logreg/reddit_ai_detector.joblib
```

### `predict.py`

Runs the trained model on one comment passed from the command line.

What it does:

- Loads the saved `.joblib` model.
- Classifies the provided text as `AI` or `HUMAN`.
- Prints class probabilities from `predict_proba`.

Example:

```bash
uv run python tf-logreg/predict.py --text "This is a sample Reddit comment."
```

With an explicit model path:

```bash
uv run python tf-logreg/predict.py --model tf-logreg/reddit_ai_detector.joblib --text "This is a sample Reddit comment."
```

### `test_data.py`

Evaluates an already trained model on an external labeled CSV file.

Expected input columns are the same as for training:

```csv
comment,label
```

What it does:

- Loads the saved model.
- Loads the test CSV.
- Removes rows with missing comments or labels.
- Predicts labels for all comments.
- Prints accuracy, classification report, and confusion matrix.

Example:

```bash
uv run python tf-logreg/test_data.py --data data/test.csv
```

With an explicit model path:

```bash
uv run python tf-logreg/test_data.py --model tf-logreg/reddit_ai_detector.joblib --data data/test.csv
```

### `reddit_ai_detector.joblib`

Saved trained model used by `predict.py`, `test_data.py`, and the FastAPI app in `app.py`.

The file contains the full `sklearn` pipeline:

- TF-IDF feature extraction.
- Feature union of word and character features.
- Logistic regression classifier.

Because the feature extraction is saved together with the classifier, new text can be passed directly to `model.predict(...)` or `model.predict_proba(...)` without manually transforming it first.

## Model Summary

The classifier is a linear model over sparse text features.

For a comment vector `x`, logistic regression computes:

```text
z = w^T x + b
P(AI | x) = 1 / (1 + exp(-z))
```

The final label is the class with the higher predicted probability.

The probability should be interpreted as model confidence, not proof that the author is actually human or AI.

## Known Limitations

- The model only sees text, so it cannot use account behavior or posting patterns.
- It depends on the training data distribution.
- Newer AI writing styles may reduce performance over time.
- Formal human writing can be misclassified as AI.
- AI text with deliberate mistakes can be misclassified as human.
